## Boilerplate (short)
Abandoned Dunes is a free, offline, ad-free slingshot golf game for iPhone and iPad. Pull back to set power and aim, read the live wind dial and play seven parody-named coastal links courses. Course names are parodies; the game is not affiliated with any real golf course or resort.

## Key features
Real gusting wind; smart club suggestions; putting with true green slopes; 18, 9 or custom rounds; leaderboards per course and difficulty; haptics; private and offline.
